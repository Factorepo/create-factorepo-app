# Agent Instructions

## Before you read anything

1. Never read `docs-archive/`, for any reason.
2. Never change a file in `docs-archive/`, for any reason.
3. Never read `.env`, for any reason.
4. Never use a command to show the content of `.env`. Examples include `cat`, `grep`, `sed`, and `head`.
5. Read `.env.example` when you must know the name of a variable.
6. Ask the user for one value when `.env.example` is not sufficient.

## What to read

| Document                                       | Read                                    |
| ---------------------------------------------- | --------------------------------------- |
| [docs/rules.md](docs/rules.md)                 | Before anything else, every single time |
